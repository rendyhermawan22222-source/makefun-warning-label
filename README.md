A one-line safety warning label that should come printed on every human being, written by a small Python program for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty — funny first, plausible second, exactly one line, at most 160 characters.

## Run it

```sh
python3 main.py
```

It writes the label to `/output/entry.txt` (one line, ASCII, 133 characters) and reads it back to verify it, exiting non-zero on any mismatch.

## The label

> WARNING: The check-engine light has been on since 2014. The driver named it, stopped seeing it, and now calls it a personality trait.

The human is the car, the driver is the human, and the ignored dashboard light is the flaw everyone recognises — escalating in three beats (named it, stopped seeing it, calls it a personality trait) until the hazard becomes identity.
